# ADR 003: Optional local Morgue experience rehearsal

- Status: Accepted for local demonstration
- Date: 2026-10-04 (America/Chicago)
- Authorization: Dominique requested implementation of the operator/participant Ink demo.

Add a separate optional `morgue/` workspace, preserving the default artist workflow. Bundle inkjs 2.4.0 and its MIT license so the Ink story runs without a CDN or runtime network requirement. Author original demonstration prose; character cues are labelled drafts rather than canon or migrated bot behavior.

The operator rehearses scene release and character approval while a simulated participant chooses branches on the same device. All state stays in memory and resets on reload. This introduces no canonical identity, durable record, private ingestion or external action. No communications beat schema is consumed. Existing Yellow Door story source remains unchanged.

Remote participant synchronization and Germ/Roomy messaging require separate architecture, consent and integration review. A simulation must not distribute the real invitation: a win shows the reward preview and links to the actual browser game. Dominique retains separate human-approved invitations in Roomy.
