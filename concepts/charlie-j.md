# Charlie J / Creator OS case study

This is a design case study, not an official Charlie J product or endorsement.

The existing `50-ways-to-leave-another` Charlie concept explores an artist-owned professional site around performance, writing, production, EP collaboration, rights, scope, and retained ownership. PIXIE Creator OS treats that work as a possible creator workflow to prototype, while keeping the OS itself generic enough for a social-network DJ.

The DJ-specific instance adds:

- crate and set preparation
- deck/transport concepts
- Mixxx and controller boundaries
- audio routing visibility
- AT Protocol social identity
- plyr.fm publishing target
- Streamplace live target
- private communication adapter target
- project and rights records

No external service account is connected by this prototype.
